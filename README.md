### Инженерия высоких нагрузок и чистый UX

Я — **Full Stack Software Engineer**, фокусирующийся на создании быстрых, защищенных и масштабируемых веб-систем. Мой подход объединяет строгую серверную логику с современным интерфейсом в стиле **Linear, Apple и Vercel**.

Сейчас мой основной приоритет — **Conlink Messenger**, современная платформа обмена сообщениями в реальном времени, построенная на реактивном JavaScript на клиенте и высокопроизводительном PHP/MySQL ядре на сервере.

* **Направление:** Full Stack Разработка, Архитектура БД, Real-Time API
* **Принципы:** Нулевая избыточность, strict typing, высокая скорость загрузки (sub-100ms TTFB)
* **Дизайн:** Минимализм, темные футуристичные темы, аккуратная типографика
